# RepRight — Screen HTML Prototypes

These are static HTML mockups of all RepRight screens.
Open each file directly in a browser — no build step needed.

## Files

| File | Screen | Nav Tab |
|---|---|---|
| `01-home.html` | Home dashboard | Home (active) |
| `02-workout.html` | Configure session | Workout (active) |
| `03-live-session.html` | Live analysis + skeleton overlay | Workout (active) |
| `04-session-complete.html` | Post-session summary + score | Workout (active) |
| `05-stats.html` | Rep log + weekly chart | Stats (active) |
| `06-profile.html` | User profile + settings | Profile (active) |
| `07-demo-mode.html` | Demo mode screen | Workout (active) |

## Tech
- Tailwind CSS (CDN)
- Space Grotesk + Inter (Google Fonts)
- Material Symbols Outlined (Google Fonts)
- No JS framework — pure HTML/CSS

## Design Tokens
See `../design-system.md` for full color, typography, and component specs.
All React Native equivalents are in `src/theme/colors.ts` and `src/theme/typography.ts`.
